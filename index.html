Phần Mềm Đảo Đề Tiếng Anh (Chuẩn 2026)

Đảo phần, Đảo đáp án, Cố định thứ tự câu trong phần & Tự động cập nhật số câu hỏi trong bài đọc.

1. Dữ liệu Đề Thi Gốc (Định dạng JSON)

Hỗ trợ tự động phân tích cấu trúc đề chuẩn từ file Word.

2. Cấu hình Đảo đề

✅ Đã đảo xong! Đang xuất file...
Hướng dẫn sử dụng:
  • Bạn có thể bấm chọn file .docx gốc để hệ thống tự phân tích và sinh mã JSON vào ô bên cạnh.
  • Trong phần instruction hoặc passage, hãy dùng cú pháp {số_câu} (ví dụ: {15}). Khi đảo đề, hệ thống sẽ tự động tìm và đổi số đó thành số thứ tự câu hỏi mới tương ứng.
  • Hệ thống tự động căn chỉnh trình bày và độ dài các phương án giống hệt bản gốc khi xuất ra file Word.
